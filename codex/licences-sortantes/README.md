# /codex/licences-sortantes/ — nos licences à revendre / louer

> L'agent RÉDIGE le document complet (contrat, prix, conditions), pas une idée de contrat (CODEX §11).
> Bloqué uniquement : l'envoi à un client réel et la signature (humain, §10).
> Brevets : recherche d'antériorité seulement ; jamais de revendications ni de dépôt ; rien n'est « breveté » tant que rien n'est déposé.

## Format d'une fiche licence sortante (CODEX §7)
ID / Composant / Modèle envisagé / Document créé (contrat complet rédigé) / Vérifications avant usage réel / Statut : PROPOSÉ ET RÉDIGÉ.
