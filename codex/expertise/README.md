# /codex/expertise/ — TRANSVERSE (partagé entre tous les projets)

> Ce qu'un projet apprend, tous les autres le savent. C'est la seule raison pour laquelle un Empire vaut
> mieux qu'une pile de dossiers séparés (CODEX §4). Un fichier par domaine : /codex/expertise/[domaine].md.
> On consigne le PRINCIPE appris (le COMMENT), jamais le code copié.

## Format d'une fiche expertise (CODEX §7)
ID / Domaine / Principe appris / Sources liées / Projets où appliqué / Fiabilité (FAIBLE/MODÉRÉE/ÉLEVÉE) / Date de dernière confirmation.

Maturité d'un domaine (en-tête du fichier de domaine) : DÉBUTANT (< 3 fiches) / CONFIRMÉ (3-10) / EXPERT (> 10, sur 2+ projets).
